【重要】お問い合わせ情報の漏えいのおそれに関するお詫びとお知らせ
このたび、当社がお問い合わせの対応のためにお預かりしている情報の一部が、2
 件の不正アクセスにより、外部に漏えいしたおそれがあることが判明しました。現時点で、情報が公開されたり悪用されたりした事実は確認していません。
お客様ならびに関係者の皆様に多大なるご迷惑とご心配をおかけしておりますことを、深くお詫び申し上げます。
対象となる方には、当社からメールで個別にご連絡いたします。本件の概要を、下記のとおりお知らせいたします。
記
1. 漏えいのおそれがある情報
（1）ウズへのお問い合わせ
対象の方: 2026年3月30日から10月14日までに、ウズへお問い合わせをいただいた方（544 名）
項目: メールアドレス、電話番号、お問い合わせの内容（ユーザー
 ID、添付いただいたファイルを含む）
原因:
 2026年10月14日、当社のメールアカウントが第三者に不正に利用され、お問い合わせの管理システムに社員になりすましてログインされました。
（2）当社 Web サイトのお問い合わせフォーム
対象の方: 2026年4月までに、当社 Web
 サイト（sally-inc.jp）のフォームから送信いただいた方（404 名）
項目:
 氏名、メールアドレス、お問い合わせの内容（フォームによっては、会社名、部署名、役職、電話番号を含みます）
原因: 当社が以前 Web サイトの制作に利用していたサービス「Studio」を運営する
 Studio株式会社のクラウド環境に、2026年9月30日から10月1日にかけて不正アクセスが発生したことを10月16日に報告を受けました。
※
 ウズのアカウントにご登録の連絡先、アプリ内のメッセージ、クレジットカード情報は含まれていません。
2. 当社の対応
いずれも不正なアクセスはすでに遮断されています。当社では、社員アカウントの保護とシステムの修正を行いました。現在の当社
 Web サイトは Studio
 を利用していません。今後、社員アカウントの多要素認証の徹底や監視の強化など、再発防止に努めてまいります。
個人情報保護委員会へは、2026年10月17日に報告しました（Studio
 の件は、Studio株式会社との連名で報告します）。
