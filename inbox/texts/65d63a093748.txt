 当社が利用するチャットサービスへの不正アクセスに伴う個人情報漏えいの可能性について 
このたび、当社
Web
サイトのお問い合わせ対応に利用しているチャットサービス「
ChatPlus
」の提供元であるチャットプラス株式会社において、第三者による不正アクセスが発生したことが判明しました。
お客様にはご心配をおかけしておりますことを深くお詫び申し上げます。
現在、チャットプラス株式会社において、不正アクセスの詳細、情報流出の有無および影響範囲について調査が進められています。
現時点で判明している内容について、以下のとおりお知らせいたします。
1．事案の概要
2026年
11
月
13
日（金）、チャットプラス株式会社が提供する「
ChatPlus
」の一部
Web
サーバーにおいて、第三者による不正アクセスが発生しました。同社は、
11
月
17
日（火）に検知し、同日、不正アクセスの遮断措置を実施しました。
2．流出の可能性のある情報
当社
Web
サイトのチャット機能を利用してお問い合わせいただいたお客様の、以下の情報が対象となる可能性があります。
会社名
氏名
メールアドレス
チャットでの会話内容
現時点では、情報流出の有無および影響範囲について確認中です。
なお、本件の対象となる可能性があるのは、当社
Web
サイトのチャット機能を利用して入力・記録された情報に限られます。
3．お客様へのお願いと二次被害防止のための注意喚起
本件に関連して、当社や関係先を装った不審なメールなどが送信される可能性があります。
不審なメールを受信した場合は、記載された
URL
へのアクセスや添付ファイルの開封などを行わないようご注意ください。
4．当社の対応
当社では、チャットプラス株式会社による調査状況を確認するとともに、当社のお客様への影響について把握を進めています。
なお、予防的措置として、現在、当社
Web
サイトのチャット機能を停止しております。
今後、新たに公表すべき事実が判明した場合には、当社
Web
サイトなどを通じて速やかにお知らせいたします。
