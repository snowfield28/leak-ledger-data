Title
WP Duplicate <= 1.1.11 - Unauthenticated Arbitrary File Upload via Authentication Bypass
Summary
The WP Duplicate WordPress plugin through 1.1.11 does not properly verify a request authentication value and does not validate the path or type of uploaded files, making it possible for unauthenticated attackers to write arbitrary files to the server and achieve remote code execution. This vulnerability is being actively exploited in the wild.

How durations are calculated
Following the VTEM framework (Black Hat USA 2015), time to patch starts when the vendor or a coordinator was informed,
 total time to patch at discovery, and disclosure to patch at public disclosure; vendor response time runs from the report
 to its acknowledgement. Time to exploit and time unpatched start at the earliest discovery or report, falling back to public
 disclosure. Unpatched time ends at the first recorded patch, or the calculation time when no patch is recorded. Exploitation
 to patch shows the interval between those two events; a published proof of concept is a public exploit, not exploitation.
Each result shows its source dates. A negative interval means the end event came first; when date-only inputs leave
 the order open, the result says so. Date-only inputs are approximate. The earliest evidence wins: KEV report dates and
 sightings are labelled as such. Records describing another vulnerability are listed but never calculated from, and a
 PoC alone does not establish exploitation.
 Missing patch evidence does not prove that no patch exists. Filters below change the event list only.
