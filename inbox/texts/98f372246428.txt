バンダイナムコ、バンダイスピリッツ のTHE GUNDAM BASE MEMBERS で34万6,247件の個人情報漏洩の恐れ-ユミルリンクへの不正アクセスが波及、バンダイナムコIDが発表
株式会社バンダイナムコエンターテインメントと株式会社BANDAI SPIRITSは2026年10月27日21時、会員向けサービス「THE GUNDAM BASE MEMBERS」の登録情報346,247件が外部に漏えいしたと発表しました。バンダイナムコIDのメールサービスを委託しているユミルリンク株式会社への不正アクセスによるものです。対象となる情報はメールアドレスとバンダイナムコID管理用の内部識別子で、ログインパスワードやクレジットカード情報は含まれないと説明しています。

バンダイナムコID、THE GUNDAM BASE MEMBERSを利用するサービス
メール配信の委託先に不正アクセス 10月26日に情報取得の報告
BANDAI SPIRITSは「THE GUNDAM BASE MEMBERS」で、バンダイナムコエンターテインメントが運営する「バンダイナムコID」のメールサービスを利用していました。10月26日、委託先のユミルリンクから、そのうちTHE GUNDAM BASE MEMBERSの利用環境について、不正アクセスとメールアドレス等の情報を取得した形跡が見つかったとの報告を受けています。
このため、今回の漏えいはガンダムベースの店舗システムや、会員サービスのログイン基盤そのものへの侵入が発表された事案ではありません。影響が確認されたのは、外部事業者に委託していたメール配信環境です。ただし、ユミルリンクへ委託している他のメール配信環境への影響については、発表時点で調査が続いています。
ユミルリンクは10月26日に公表した
「Cuenote FC」不正アクセス第2報
で、プログラム・ライブラリの脆弱性を起点に、サポート・品質管理担当者の認証情報の取得、不正プログラムの設置、データベースからの情報出力、他システムへのアクセスが確認されたと説明しています。バンダイナムコ側の発表は、この委託先への攻撃が個別の会員サービスへ波及した事例です。
メールアドレスと内部識別子346,247件が対象 パスワードや購入履歴は含まれず
公表された情報項目は二つです。一つは会員が登録したメールアドレス、もう一つはバンダイナムコIDの管理に使う内部識別子です。内部識別子は会員をサービス側で管理するための情報であり、ログインパスワードが流出したという意味ではありません。
両社によると、氏名、住所、購入履歴などのその他の登録情報に加え、ログインパスワードやクレジットカード情報も漏えい対象に含まれません。公表値の346,247件は対象情報の件数であり、同じ数の個人に被害が発生したと独立に確定できる人数の集計ではありません。
対象者には改めて連絡するとしています。退会済みなどの理由で個別連絡ができない場合は、公式サイトでの告知や必要に応じた続報をもって通知に代える方針です。

ユミルリンク全体では延べ5,162万8,280件 個別発表分を重複加算しない
ユミルリンクは10月26日の第2報で、メール配信サービス「Cuenote FC」の49システムに情報の外部出力の痕跡があり、漏えいのおそれがあるデータを延べ51,628,280件と公表しました。対象システムのうち16システムでは件数の調査が継続中です。
今回の346,247件はユミルリンクの事案を受けて利用企業側が明らかにした個別の影響規模です。ユミルリンクが公表した延べ件数との包含関係を利用環境単位で精査せず、両者を足し合わせて新たな被害総数とすることはできません。同じメール配信基盤を使う企業への影響は、
Cuenote FCの影響企業・団体まとめ
で整理されています。
メール配信を停止 会員サービス自体は継続利用可能
バンダイナムコエンターテインメントとBANDAI SPIRITSは、影響を受けたTHE GUNDAM BASE MEMBERSのメール配信サービスを停止しました。一方、バンダイナムコIDおよびTHE GUNDAM BASE MEMBERSを使用するサービスは引き続き利用できます。
10月27日には個人情報保護委員会への報告を行い、ユミルリンクと連携して原因究明と影響範囲の調査を続けています。公式発表時点で、本件に起因する情報の不正利用などの二次被害は確認されていないとしています。
対象者にとって当面の注意点は、流出したメールアドレスを利用したなりすましやフィッシング詐欺です。両社は本件に関する連絡メールの本文にURLを記載しない方針を示しました。会員向けのお知らせを装ったメールが届いても、記載されたURLからログインしたり、認証情報・決済情報を入力したりせず、公式サイトを直接開いて案内を確認する必要があります。
企業の情報システム部門が確認したい委託メール配信のリスク
今回の事案では、会員サービスが通常どおり利用可能な一方、通知に用いるメール配信環境から情報が流出しました。会員情報を扱う企業では、基幹サービスと外部メール配信基盤を分けて影響範囲を管理し、委託先で障害・侵害が発生した際にどのデータを預けていたかを速やかに特定できるかが課題になります。

委託先に保存したデータ
配信用メールアドレスだけでなく、内部IDや差し込み項目、配信ログも棚卸しする
外部サービスの管理権限
管理画面・APIのアクセス元制限、委託先サポートアカウントの権限、認証情報の管理方法を確認する
事故時の通知手段
メール配信が停止しても公式サイトや会員画面など別経路で通知できるようにする
なりすましへの対応
正規の案内方法を告知し、メール・ドメインをかたる偽通知の通報先を案内する
委託先との連絡体制
発生時刻、持ち出しが確認されたデータ、対象件数、追加調査の予定を継続的に照会する
不審メールを受信した従業員がリンクを開かずに報告できるかを検証する場合は、訓練内容や通報機能などの観点から
標的型攻撃メール訓練サービスを比較
する方法もあります。こうした訓練は委託先からの情報流出そのものを防ぐものではなく、流出後の悪用を想定した対策です。
