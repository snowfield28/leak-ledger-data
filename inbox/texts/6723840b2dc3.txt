3.1 Windows イベントログとは
Windows イベントログの概要
Windows イベントログ（以下、 「イベントログ」 ）は、OS、アプリケーション、ドライバーなど
で発生した出来事（イベント）を記録しているログファイルです。
イベントログは、以下のような場面で活用されます。
・トラブルシューティング：システムエラーやアプリケーション異常の原因調査
・セキュリティ監視：不正アクセスやマルウェア感染の検知
・インシデント調査：攻撃の痕跡調査、侵入経路の特定、影響範囲の把握
イベントログには、ログオン、コマンド実行、ファイルアクセス、外部通信などの痕跡が記録さ
れており、インシデント調査において「何が起きたか」を推定するための手掛かりとなります。
イベントログの種類
Windows には複数の種類のイベントログがあり、それぞれ異なる内容が記録されます。主要な
イベントログの種類を以下に示します。

イベントビューアーは、イベントの詳細情報を確認できる有用なツールですが、表示される情

次章では、攻撃パターンの検出や複数種類のイベントログを横断した分析といった、イベン
トビューアーでは手作業でしかできない分析を高速に実施できる脅威ハンティングツール
Hayabusa について紹介します。
4.　Hayabusa の基礎
4.1 Hayabusa とは
Hayabusa は、日本を拠点として活動するセキュリティグループの Yamato Security によって開
発された、イベントログのファストフォレンジックタイムライン作成および脅威ハンティング
ツールです。
Hayabusa の主な特徴は以下の通りです。
・高速処理：大量のイベントログを短時間で処理可能
・Sigma ルール対応：脅威検知ルールの共通フォーマットである Sigma ルールでの解析に対応
・タイムライン生成：調査に有用なデータのみを抽出し、タイムラインを生成
18
Hayabusa は、Sigma ルールを独自の Hayabusa ルールに変換して読み込み、イベントログに
対してマッチング処理を行うことで、既知の攻撃パターンを検出します。検出されたイベント
は重要度で分類され表示されるため、イベントログに関する深い知見がなくても効率良く解析
を行うことができます。
