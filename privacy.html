プライバシーポリシー

最終更新：2026年10月12日

このサイトで集める情報

このサイト自体では、閲覧者の氏名・メールアドレスなどの入力を求めません（お問い合わせフォームは別です。下記をご覧ください）。このサイトは、広告のためのツールを使用していません。アクセス解析については、下の「アクセス解析」をご覧ください。

サイト内の設定（絞り込み条件など）は、閲覧している端末の中だけで処理し、運営者には送られません。

アクセス解析

このサイトでは、閲覧状況（どのページがどれだけ見られているか）を把握するため、アクセス解析サービス GoatCounter を使っています。提供元の説明によると、GoatCounter は閲覧者のブラウザに Cookie などを保存せず、IP アドレスも保存しません。集計されるのは、ページビュー数と参照元、ブラウザの名前とバージョン、OS、言語、画面幅、IP アドレスから判定した国・地域です。これらは統計として集計して使い、閲覧者を個人として特定することはありません。トップページの下部には、GoatCounter が集計した全ページの累計訪問者数（延べ人数）を表示しています。この数字は誰でも見られます。提供元は、情報を第三者へ提供しないとしています。取り扱いは GoatCounter のプライバシーポリシーをご覧ください（英語）。

ホスティング事業者による記録

このサイトは GitHub Pages（GitHub, Inc.）で公開しています。GitHub Pages では、セキュリティのために、閲覧者の IP アドレスが GitHub によって記録・保存されます。取り扱いは GitHub のプライバシーステートメントをご覧ください。運営者はこの記録を受け取っていません。

お問い合わせでいただく情報

お問い合わせフォーム（Google フォーム）に入力された内容は、お問い合わせへの回答と掲載内容の確認・訂正のためにだけ使い、ほかの目的には使いません。法令に基づく場合を除き、第三者に提供しません。フォームの入力内容は Google LLC のサービス上に保存されます。フォームのページでは Google が Cookie などを使うことがあります。取り扱いは Google のプライバシーポリシーをご覧ください。氏名・メールアドレスなどの個人情報の入力は必須ではありません（返信が必要な場合のみ、メールアドレスをご記入ください）。パスワードやクレジットカード番号など、本件に不要な情報は入力しないでください。

外部サイトへのリンク

このサイトには、各組織の公式発表や報道機関の記事へのリンクがあります。リンク先での情報の取り扱いは、それぞれのサイトの方針によります。

このポリシーの変更

広告を導入するなど、取り扱いを変える場合は、このページを更新してからにします。
